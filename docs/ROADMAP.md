# Roadmap

## MVP 0.1

- App mobile con dati demo locali e architettura servizi.
- Supabase schema, RLS, seed e Edge Functions.
- Admin panel web con viste principali.
- Test minimi e CI.

## MVP 0.2

- Collegare repository Supabase reali nell'app mobile.
- Signup, password reset, session persistence.
- Sincronizzazione Realtime per gruppi e commenti challenge.
- Upload avatar su Storage.
- Admin login con role check.

## Beta 0.3

- Moderazione completa: report queue, audit log visibile, azioni su contenuti.
- Notifiche FCM reali: challenge reminder, weekly summary, milestone.
- A/B copy per onboarding e streak.
- Accessibilità e localizzazione completa IT/EN con file ARB.

## Beta 0.4

- Offline-first cache locale.
- Deep link invito gruppo.
- Widget grafici piu evoluti mantenendo dipendenze free.
- Export dati utente.

## Store 1.0

- Privacy/terms definitive.
- App icon, store screenshots, release signing Android/iOS.
- QA su dispositivi reali.
- Monitoraggio crash free-tier.
- Hardening RLS con test SQL automatizzati.
